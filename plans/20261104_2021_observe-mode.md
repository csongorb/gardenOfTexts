# Observe mode

## Context
The readme already says "for you to *observe, water, and cut*", but the interface only has the two acting modes, water and cut. The new mode, **observe**, does nothing: no tool circle and no effect on the garden. You can simply watch. Its label in the bottom left corner is green. The garden starts in observe, and the modes appear in the order **observe / water / cut**.

## Changes

**[index.html](index.html)**: change the tools line to
`<span data-mode="observe">observe</span> / <span data-mode="water">water</span> / <span data-mode="cut">cut</span>`.
The existing click handler in `setup()` ([js/sketch.js](js/sketch.js)) picks up the new span automatically.

**[js/config.js](js/config.js)**: add a green `observe` entry to `TOOL_COLORS`, e.g. `observe: [0.30, 0.11, 145]`. It has the same lightness and chroma as the others, with a green hue. `lightToolColor()` turns it into the light green of the active label. The comment notes that observe only uses it for the label.

**[js/interaction.js](js/interaction.js)**
- `var toolMode = 'observe';`, and update the comment: "'observe': nothing, just watch / 'water': … / 'cut': …; right click cycles through them".
- `drawToolCircle()`: return early when `toolMode === 'observe'`, so no circle is drawn.
- Right click: cycle **observe → water → cut → observe** via a small `TOOL_MODES = ['observe', 'water', 'cut']` list in `interaction.js`. The next mode is `TOOL_MODES[(TOOL_MODES.indexOf(toolMode) + 1) % TOOL_MODES.length]`. This replaces the water/cut toggle.
- Watering (`CharPlant.grow`) and cutting (`mousePressed` / `mouseReleased`) already check for their own mode, so observe needs nothing else.

**[readme.md](readme.md)**: add an "Observe" row to the "How to play" table, describing it as "just watch, the default". Update "Switch mode": right click cycles through the modes, or tap/click them in the bottom left.

## Verification
- `node --check` passes on all JS files.
- In the browser, the page starts with a green "observe", no circle, and hovering doesn't speed up growth.
- Right click cycles observe → water (blue circle) → cut (red circle) → observe.
- Clicking the labels switches modes.
- On touch, tapping "observe" works, and taps on the garden don't cut.
